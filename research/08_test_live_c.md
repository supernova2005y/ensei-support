# 試走③：公演C（国内のシンガーソングライターの公演・1月の土曜・大阪）（2026-11-20実施、未来の公演）

名古屋から大阪の会場へ行く場合を、Web 検索と公式の時刻表で調べた。東京以外の会場で試すのは初めて（`docs/開発のTODO.md` フェーズ3「別の会場・別の地域でもう1件試す」）。

## 入力
- 「1月の土曜にある、大阪の公演に名古屋から行きます」だけ

## 公演（公式サイトの公演ページで確認）
- 会場：大阪市中央公会堂（中之島）。建物全体を使い、大集会室でライブ、ほかの部屋で館内の企画
- 開場17:15・開演18:00。館内の企画は「昼過ぎから順に始まる予定」（時刻は未発表）
- 席：1・2階 指定席 13,000円、2階 注釈付き自由席 11,000円（税込）。チケットがあれば館内の有料エリアにも入れる
- 終演の発表はない → 目安として 20:15（開演＋約2時間15分）にした

## 行き方（名古屋 → 大阪）
| 手段 | 料金（片道の目安） | 所要時間 | メモ |
|---|---|---|---|
| のぞみ 指定席（名古屋→新大阪） | 6,680円（自由席 5,940円） | 約50分 | 新大阪から御堂筋線で淀屋橋まで約12分 |
| 近鉄特急（近鉄名古屋→大阪難波） | 4,990円前後（ひのとり レギュラー） | 約2時間 | 料金は記事で差がある。公式で未確認 |
| 昼行の高速バス（名古屋駅→大阪駅） | 2,100〜3,100円 | 約2時間50分 | 夕方以降の便は未確認 |

- のぞみの特急料金は 2027年7月1日購入分から値上げと発表されている（今回の公演には関係ない）

## 日帰りできるか（帰りの最終便）
- 新大阪 → 名古屋の最終は **22:30発 のぞみ108号（名古屋 23:20着、毎日運転）**。1本前は 22:00発 のぞみ106号（22:49着）
  - JR西日本の時刻表（JRおでかけネット）の列車のページで確認。人はまだ確かめていない → `data/last-trains.json` は `verified: false`
- 会場 → 新大阪は、徒歩6分＋御堂筋線 約12分＋待ち時間で、約25分（目安・未確認）
- アプリの判定（退場20分・駅の中10分をみる）だと、**終演が 21:35 までなら最終に間に合う**。終演の目安 20:15 から1時間以上の余裕がある → **日帰りできる**
- 近鉄特急の最終（大阪難波発）は21時台という古い情報しか見つからず、未確認。公演の後は新幹線が安全

## 泊まる場合
- 宿の空室・料金はまだ調べていない（楽天のキーがある PC で `node scripts/rakuten-vacant.mjs --event events/live-c.json` を実行する）
- 行きやすい駅：なにわ橋・淀屋橋・北浜（徒歩圏）、本町・大阪（梅田）・新大阪（御堂筋線で1本）

## 寄り道の候補（会場から歩ける中之島）
- 公演の館内の企画（昼過ぎから。チケットがあれば全エリアに入れる）
- 大阪中之島美術館：女性の作り手の100年をたどる展覧会（2027年1月9日〜3月22日）、大英博物館の江戸絵画の巡回展（〜2027年1月31日）
- 国立国際美術館：特別展（2026年12月1日〜2027年3月14日）
- 美術館の会期は展覧会情報サイトの一覧で確認。公式サイトでは未確認

## わかったこと（設計への反映）
- **会場の建物全体がイベントになっていて、昼から楽しめる。** 「開場前の空き時間に寄り道を詰める」だけでなく、「会場そのものに早く行く」案も出せるとよい
- **最終便の表は区間ごとに足す必要がある。** 東京の公演用に作った表（東京・品川 → 名古屋）を、新大阪 → 名古屋に広げた。行き先の地域が増えるたびに、表を足すか、時刻表つきの API を使うかを決める
- 名古屋 → 大阪は「新幹線は速いが高い・近鉄は安くて座れる・バスは最安」の3つで差が大きい。東京よりも、近鉄を選ぶ人が多そう
