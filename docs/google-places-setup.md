# Google Places API の準備（キー・予算アラート・回数の上限）

`scripts/google-places.ts`（とあとで画面）で、会場や駅の周りのパン屋・洋菓子店などを探し、公演の日に開いているかを確かめるための準備です。

使った分だけ料金がかかるAPIなので、**「予算アラート」と「1日の上限」の両方**を設定してから使います。

---

## 料金のしくみ（2026年の調査時点）

- 1回の検索で取り出す項目によって料金が変わります。
  - **営業時間・評価も取る（Enterprise）**：1,000回で35ドル。**毎月1,000回まで無料**
  - **名前・場所・営業状態だけ（Pro）**：1,000回で32ドル。**毎月5,000回まで無料**
- このアプリは営業時間を見たいので Enterprise です。1回のプランで会場と7駅を探すと8回なので、**月125プランくらいまで無料**です。
- 料金は変わることがあるので、Google の料金ページ（Google Maps Platform の Pricing）で確かめてください。

---

## 1. Google Cloud でプロジェクトを作る

1. https://console.cloud.google.com/ を開き、Google アカウントでログインします。
2. 上の「プロジェクトを選択」→「新しいプロジェクト」で、名前（例: `ensei-support`）を付けて作ります。
3. 「お支払い（Billing）」で請求先アカウントを作り、クレジットカードを登録して、このプロジェクトにつなぎます。

## 2. Places API (New) を有効にする

1. 「APIとサービス」→「ライブラリ」で **Places API (New)** を探して「有効にする」を押します。
   - 名前が似た古い「Places API」ではなく、**(New)** の方です。

## 3. APIキーを作って、使えるAPIを絞る

1. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」。
2. できたキーの「キーを編集」で、**APIの制限 → キーを制限 → Places API (New) だけ**にチェックして保存します。
   - これで、キーが漏れても Places 以外には使われません。
3. キーを Codespaces の `.env` に書きます（チャットやコミットには貼らない）。
   ```
   GOOGLE_PLACES_API_KEY=（作ったキー）
   ```

## 4. 予算アラートを設定する

1. 「お支払い」→「予算とアラート」→「予算を作成」。
2. 対象をこのプロジェクトにして、金額を決めます（例: **500円**）。
3. アラートの割合を **50%・90%・100%** にして、メールで知らせるようにします。

**注意**：予算アラートは**知らせてくれるだけで、使うのを止めてはくれません**。料金の集計にも数時間〜1日の遅れがあります。なので、次の「1日の上限」も必ず設定します。

## 5. 1日の呼び出し回数に上限を付ける（ここで本当に止まる）

1. 「APIとサービス」→「有効なAPI」→ **Places API (New)** →「割り当てとシステム上限（Quotas）」を開きます。
2. **SearchNearby の1日あたりのリクエスト数**（「per day」の行）を探し、編集して上限を入れます（例: **100回/日**）。
3. 上限に達すると、その日はエラーになって止まります（料金はかかりません）。

## 6. スクリプトの数え方（3つ目の守り）

- `scripts/google-places.ts` は、呼んだ回数を `out/google-places-usage.json` に**月ごと・料金の種類ごと**に数えます。
- 月の上限（既定 900回。Enterprise の無料枠 1,000回より少し下）を超えそうなら、**呼ぶ前に止まります**。
- 呼ぶ回数だけ先に確かめるなら `--dry-run` を付けます（APIは呼びません）。
  ```bash
  node scripts/google-places.ts --event events/live-b.json --category パン屋 --dry-run
  node scripts/google-places.ts --event events/live-b.json --category パン屋
  ```
- このファイルは Codespaces の中だけにあります。別のパソコンや画面（Vercel）から呼んだ分は数えられないので、全体の回数は Google Cloud の「APIとサービス」→「指標」で確かめます。

---

## 守りのまとめ

| 守り | 止まるか | 遅れ |
|---|---|---|
| スクリプトの数え方（月900回） | 止まる（そのパソコンで呼んだ分だけ） | なし |
| Google Cloud の1日の上限（例: 100回） | **止まる（全部の呼び出し）** | なし |
| 予算アラート（例: 500円） | 知らせるだけ | 数時間〜1日 |
