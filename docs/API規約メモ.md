## 今の作りとの照らし合わせ
| 規定 | 今の作り |
|---|---|
| 店名・住所などの第三者DBへの複製保存は禁止 | 保存しない（表示のたびに取る） |
| キャッシュは、個別の規定がなければ24時間以内に更新・削除 | キャッシュなし |
| 「リクルートより提供」の表示・クレジットの変更禁止 | フッターと店の一覧の下に表示 |
| 回数の上限 | 公式の数字は見つからず。自前の上限（1分1回・1日10回・全体1日200回）で絞る |

## 確認中：アフィリエイト（収入）
- 利用規約の禁止行為：「API の利用もしくは提供から収入を得ることはできません」（書面の承諾がない限り）
- FAQ：「リクルート Webサービス利用規約に反しない限り、アフィリエイトプログラムを利用することができます」
- ご利用案内：「アフィリエイトにより収入を得ることは問題ありません」
- 読み方が分かれるので、お問い合わせフォームで確認する。**確認が取れるまで、ホットペッパーのリンクにアフィリエイトを付けない。**

## お問い合わせの下書き（送る前に、内容を見直してください）
お問い合わせフォーム：https://rws.zendesk.com/hc/ja/requests/new

> ホットペッパーグルメのグルメサーチAPIを、個人開発の旅行計画アプリで利用しようとしています。
> 利用規約（cdn.p.recruit.co.jp/terms/rws-t-1001）の禁止行為には「API の利用もしくは提供から収入を得ることはできません」とあり、FAQ や「ご利用案内」には「アフィリエイトは問題ありません」とあります。
> 次の2点を教えてください。
> 1. アプリに表示した店舗のページへのリンクに、アフィリエイトのパラメータを付けて収入を得ることは、許可されていますか。許可される場合は、どの条件（表示の方法・クレジット・申請の要否など）が必要ですか。
> 2. 利用規約の「キャッシュの更新は24時間以内」について、ご利用案内に個別の規定はありますか。
> 店名・住所は保存せず、表示のたびに取得する方法で利用します。
