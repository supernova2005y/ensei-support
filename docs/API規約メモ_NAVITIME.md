# API規約メモ（NAVITIME ルート検索・RapidAPI 経由）

確認日：2026-11-26 ／ 最終更新：2026-11-26

## 読んだ資料
- 利用規約（RapidAPI）：`https://api-sdk.navitime.co.jp/api/specs/description/rapid_tou.html`（2020年8月19日制定・2024年12月5日改定。ご本人が貼ってくださった本文）
- 同じページにある「API仕様書利用規約」「利用規約（テスト環境）」は、法人の導入検討向けのもの。RapidAPI 経由で使うこのアプリには、上の「利用規約（RapidAPI）」があてはまる
- この環境からは、NAVITIME・RapidAPI のページを直接開けませんでした

## 関係する条文
| 条文 | 内容（要点） | 今の作り |
|---|---|---|
| 第4条1 | ルート検索の出発地か目的地のどちらかは、自分の地点データベースから検索した地点にする | 会場の座標は `events/` に自分で入れたもの。会場を、出発地か目的地のどちらかに必ず使う |
| 第4条3 | 経路・時刻表などは、実際と違うことや正確でないことがある | 画面に「時刻表ではなく目安」と出す。RapidAPI 版の時刻は、乗り換えの待ちを平均で見込んだもの（2026-11 に確認） |
| 第5条3 | 著作権表示・商標などを消したり変えたりしない | 結果の下に「ルート検索：NAVITIME」と出す |
| **第5条5** | **受け取ったデータ（緯度経度を含む）をキャッシュなどに保存してはならない** | 結果は保存しない。`/api/route` は取った都度返すだけ（`Cache-Control: no-store`）。スクリプトも画面に出すだけで、ファイルに書かない |
| 第5条6 | カーナビ・動態管理・音声案内・位置情報ゲームなどに使わない | どれにもあたらない |
| 第5条7(1) | ソフトウェア・データなどの複製・公衆送信・改変などをしない | 返事のうち、乗車駅・所要時間・運賃だけを取り出して表示する。表示は取った都度だけ |

## 2026-11-26 に直したこと
- それまで、駅から会場までの分と路線（`events/live-b.json` の `stations`）と、会場から乗車駅までの分（`homeward.boarding`）を NAVITIME で取って保存していた → 外して「未確認」にした。人が乗換検索で確かめた値を入れる（ひな型：`research/09_live-b_所要時間の確認.md`）
- 確認用スクリプト（`scripts/navitime-route.mjs`）から、設定ファイルの書き換え（`--update`）と、返事の保存（`out/`）をなくした
- `research/06_reference_articles.md` の付録から、取った所要時間・運賃の値を外した
- 過去の Git の履歴には残っている（履歴から消すかは、ユーザーが決める）

## 回数の上限（`src/lib/navitimeQuota.ts`）
RapidAPI の Basic は月500回で止まる（Hard Limit。超えても料金はかからない）。画面からは、押したときだけ呼び、次で止める。
- アプリ全体で月100回まで（Upstash で数える）
- 同じ人（IP アドレスのハッシュ）は1日3回まで
- RapidAPI が返事に付ける残り回数が100回を切ったら止める
